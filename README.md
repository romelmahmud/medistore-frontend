# 💊 MediStore Frontend

**MediStore Frontend** is a modern, responsive e‑commerce application for browsing and purchasing medical products. Built with **Next.js (App Router)** and **TypeScript**, it integrates seamlessly with a REST API backend.

> 🚀 Live Demo: [MediStore Frontend](https://medistore-frontend-pi.vercel.app)  
> 🔗 Backend: [MediStore Backend](https://medistore-backend-11jb.onrender.com)

---

## 💡 Features

- 🛍️ Browse and search medicines
- 📄 Detailed product pages with images and descriptions
- 🛒 Shopping cart and order placement
- ☁️ Image upload via Cloudinary
- 🔒 Fully typed with TypeScript
- ⚡ Optimized for performance with Next.js App Router
- 🎨 Responsive design for desktop and mobile

---

## 🧱 Tech Stack

- **Next.js 16 (App Router)**
- **TypeScript**
- **React**
- **Nodejs**
- **ExpressJs**
- **Tailwind CSS**
- **Shadcn**
- **PostgresSQL**
- **Prisma**
- **Cloudinary** for media uploads
- **Vercel** for deployment

## 🧾 Getting Started

### 🔁 Clone the Repo

```bash
git clone https://github.com/romelmahmud/medistore-frontend.git
cd medistore-frontend

```

### Install Dependency

```bash
npm i
# or
yarn add
# or
pnpm add
# or
bun add
```

### Run on local server

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
